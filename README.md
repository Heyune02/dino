# 공룡섬 생존기 (Dino Island Survival)

탑다운 도트 그래픽 생존 RPG. 공룡이 사는 섬에 표류해 자원을 모으고, 도구를 만들고, 밤을 버티세요.

순수 HTML5 Canvas + JavaScript로 만들었고 빌드나 외부 에셋이 필요 없습니다. 모든 도트 그래픽은 코드로 생성됩니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. (또는 `python3 -m http.server` 후 `http://localhost:8000`)

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 달리기 (기력 소모) |
| 마우스 클릭 / Space | 공격 · 채집 (클릭 시 마우스 방향) |
| E | 물 마시기 · 베리 따기 · 고기 굽기 · 장작 넣기 |
| 1~6 / 휠 | 핫바 선택 |
| F / Q / 우클릭 | 선택한 아이템 사용 (먹기 · 설치) |
| C / Tab | 제작 메뉴 |
| M | 미니맵 켜기/끄기 |
| P / Esc | 일시정지 |
| N | 소리 켜기/끄기 |

## 생존 시스템

- **체력 / 포만감 / 수분 / 기력**: 포만감과 수분은 계속 줄어들고, 0이 되면 체력이 깎입니다. 둘 다 50 이상이면 체력이 천천히 회복됩니다.
- **낮과 밤**: 하루는 약 3분 30초입니다. 밤에는 시야가 좁아지고 랩터가 늘어납니다. 3일째부터는 밤에 **티라노사우루스**가 나타날 수 있습니다.
- **모닥불**: 근처에서 체력이 빠르게 회복되고, 육식 공룡이 접근하지 못합니다. 연료가 떨어지면 꺼지니 장작(나무)을 넣어주세요.
- **음식**: 베리(소량), 날고기(식중독 위험), 구운 고기(모닥불에서 E).

## 공룡

| 공룡 | 성향 | 특징 |
|---|---|---|
| 콤프소그나투스 | 육식 · 무리 | 작고 약하지만 떼로 덤빈다 |
| 랩터 | 육식 | 빠르고 위험. 밤에 많아진다 |
| 파라사우롤로푸스 | 초식 | 맞으면 도망친다. 좋은 고기 공급원 |
| 트리케라톱스 | 초식 · 방어 | 건드리면 돌진해 반격한다 |
| 티라노사우루스 | 보스 | 3일째 밤부터 출현 |

## 제작

| 아이템 | 재료 | 효과 |
|---|---|---|
| 돌도끼 | 나무 3, 돌 3 | 채집량 2배 |
| 돌창 | 나무 4, 돌 2 | 공격력 6 |
| 뼈창 | 나무 3, 뼈 4 | 공격력 11 (돌창 필요) |
| 모닥불 | 나무 5, 돌 3 | 설치형 |
| 나무 방벽 | 나무 4 | 설치형, 길을 막음 |
| 붕대 | 섬유 3 | 체력 35 회복 |
| 가죽 갑옷 | 가죽 5, 섬유 2 | 받는 피해 40% 감소 |

## 구조

```
index.html        진입점
src/util.js       수학/노이즈/효과음 유틸
src/sprites.js    문자 그리드 → 도트 스프라이트, 절차적 타일
src/world.js      섬 생성, 타일/오브젝트, 모닥불
src/entities.js   플레이어, 공룡 AI, 드롭 아이템
src/game.js       게임 루프, 렌더링, 조명, UI, 제작, 스폰
```
